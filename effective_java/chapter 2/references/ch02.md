# Chapter 2: Creating and Destroying Objects

## Overview

This chapter covers Items 1-9 from Effective Java 3rd Edition by Joshua Bloch. It focuses on the proper way to create and destroy objects, covering static factory methods, builders, singletons, dependency injection, object lifecycle, and resource management.

## Items Covered

| Item | Title | Core Concept |
|------|-------|--------------|
| 1 | Consider static factory methods instead of constructors | Object creation via static methods rather than constructors |
| 2 | Consider a builder when faced with many constructor parameters | Builder pattern for complex objects |
| 3 | Enforce the singleton property with a private constructor or an enum type | Singleton implementation |
| 4 | Enforce noninstantiability with a private constructor | Utility class pattern |
| 5 | Prefer dependency injection to hardwired resources | DI in practice |
| 6 | Avoid creating unnecessary objects | Object reuse and immutability |
| 7 | Eliminate obsolete object references | Memory management |
| 8 | Avoid finalizers and cleaners | Resource cleanup alternatives |
| 9 | Prefer try-with-resources to try-finally | Automatic resource management |

## Key Anti-Patterns in Spring Boot

1. **Using `new` for dependencies** instead of DI (Item 5)
2. **Using non-static inner classes as singletons** (Item 3)
3. **Creating objects in loops** that could be reused (Item 6)
4. **Not nullifying references** in caches (Item 7)
5. **Using `@PostConstruct` for resource cleanup** (Item 8 - avoid finalizers)
